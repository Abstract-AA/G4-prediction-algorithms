# G4-prediction-algorithms
This is a group of scripts developed to help analyze bioinformatical data about G4 quadruplexes, a unique structural motif in nucleic acid structures. The purpose of this project is to predict the three dimensional structure of RNA's and DNA's which contain a guanine quadruplex structure.

These scripts are part of a computational pipeline that requires the eltetrado software, and also rosetta for RNA structural prediction. For a complete RNA quadruplex prediction usage, a quadruplex identifier such as QGRS is also needed. 

The code is free and open source so please feel free to reuse it while crediting the original author.
